Opa, quase tudo certo! O comando ipconfig getifaddr en0 não retornou nada (a linha ficou vazia). Isso significa que o seu Mac não está conectado pelo Wi-Fi en0 — provavelmente está usando cabo Ethernet, ou o Wi-Fi está desligado, ou está em outra interface (en1, en2...).

Vamos descobrir o IP de outro jeito. Rode este comando:

bash
ifconfig | grep "inet "
Ele vai mostrar várias linhas. A que você quer é a que NÃO começa com 127.0.0.1 (esse é o localhost) e NÃO está na faixa 172.17.x.x (essa é a rede interna do Docker).

Exemplo do que vai aparecer:

text
inet 127.0.0.1 netmask 0xff000000
inet 192.168.1.42 netmask 0xffffff00 broadcast 192.168.1.255
Neste exemplo, o IP do Mac é 192.168.1.42 (a linha 192.168.x.x).

Se preferir, use o comando direto que filtra só o que interessa
Rode este (mais limpo):

bash
ifconfig | grep "inet " | grep -v 127.0.0.1 | grep -v 172.17
Ou, ainda mais elegante, no macOS:

bash
ipconfig getifaddr en1
Se en0 não funcionou, tente en1. Se der resultado, esse é o seu IP.
